Элемент проекта вида «Пользователи»

В любом проекте есть пользователи. Это предопределенный элемент проекта, который описывает пользователей, подключенных к приложению.

Примечание: О пользователях «1С:Кабинета сотрудника» вообще вы можете прочитать здесь.

Этот элемент проекта создает «1С:Кабинет сотрудника». Его не видно в структуре проекта. Вы не можете непосредственно изменять его свойства и расширять его типы.

Однако вы можете расширить этот предопределенный элемент проекта, добавив в свой проект элемент вида Пользователи с именем Пользователи. И уже у этого своего элемента проекта вы можете создать модули, чтобы, например, обработать события, связанные с пользователями.

Расширить реквизиты предопределенного элемента Пользователи нельзя.

Добавлять собственный элемент проекта вида Пользователи вы можете несколько раз, в разных подсистемах. Это может потребоваться вам для того, чтобы разными способами расширить предопределенный элемент Пользователи, в каждой подсистеме — по-своему.

Порождаемые типы встроенного языка
В любом проекте изначально содержится набор типов для работы с пользователями. Некоторые из этих типов имеют модули. С помощью этих модулей вы можете изменять стандартное поведение типа (обрабатывая его события) и расширять функциональность типа (добавляя собственные методы)
Таблица языка запросов
