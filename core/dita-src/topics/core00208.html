КонтрольФормата
Необходимость контроля формата автонумерации при записи:
  • Строгий — код справочника должен строго совпадать с форматом кода. Запись нестандартных кодов запрещена
  • Выключено — контроль не ведется, возможна запись элементов с нестандартным кодом
Поведение при записи элемента: если элементу явно задан префикс или постфикс методами УстановитьПрефикс(), УстановитьПостфикс(), то код считается стандартным и обязан совпадать с форматом. В этом случае значение свойства КонтрольФормата игнорируется.
Если префикс или постфикс не заданы, то при записи «1С:Кабинет сотрудника» разберет код на составные части и примет во внимание значение КонтрольФормата:
  • Если код стандартный (т. е. проходит контроль формата) то «1С:Кабинет сотрудника» выполнит стандартные действия: запишет вместе с элементом поля префикс, постфикс, номер и код;
  • Если код не проходит контроль формата, то:
    • Если КонтрольФормата равно Строгий — будет выдано исключение;
    • Если КонтрольФормата равно Отключен, то в поле Код будет записан код, а в поля Префикс, Постфикс и Номер будут записаны значения по умолчанию.
Пример YAML-файла:
ВидЭлемента: Справочник
Имя: МойСправочник
Ид: 64cdbccd-a768-4877-9fdd-4f7ea44c2600
Реквизиты:
    -
        Имя: Код
        Тип: Строка
        Длина: 10
        Автонумерация: 
            КонтрольФормата: Выключено
Формат
Описание формата префикса и постфикса. Имеет следующие свойства:

Количество символов в постфиксе. Число:
  • Отрицательное — длина не ограничена
  • Стандартное значение 0 (постфикс запрещен)
. Пример YAML-файла:

Имя: МойСправочник

        Длина: 10
        Автонумерация:

            Формат:

ДлинаПрефикса

  • Отрицательное — длина не ограничена
  • Стандартное значение 0 (префикс запрещен)
Пример YAML-файла:

Длина автоматически формируемого номера. Число:

  • Отрицательное — номер не дополняется нулями
  • Стандартное значение: -1

СерииНумерации
Группа элементов справочника, внутри которой будет поддерживаться уникальная нумерация:
  • ВПределахПрефикса — элементы, обладающие одинаковым префиксом
  • ВПределахПостфикса — элементы, обладающие одинаковым постфиксом
  • ВПределахПрефиксаИПостфикса — элементы, обладающие одинаковыми префиксом и постфиксом
  • Сквозной — все элементы справочника
  • Стандартное значение — ВПределахПрефиксаИПостфикса
Пример YAML-файла:

Имя: МойСправочник
Ид: 64cdbccd-a768-4877-9fdd-4f7ea44c2600
Реквизиты:

        Длина: 10

                ДлинаПрефикса: 2

ОбластьВидимости
Видимость элемента проекта (подробнее):
  • Подсистема — элемент виден внутри одной подсистемы во всех пакетах. Значение по умолчанию;
  • Проект — элемент виден во всех подсистемах одного проекта;
  • Глобально — элемент виден в других проектах.
Пример YAML-файла:
