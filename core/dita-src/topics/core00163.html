Дополнительные типы пользовательского интерфейса

Эти типы используются только как составная часть стандартных компонентов. Экземпляры этих типов нельзя добавить в проект.

  • ГруппаЭлементовОтбора — группа элементов, соединенных по «И» или по «Или» («НеИ» или «НеИли»). Используется, например, в свойстве ДинамическийСписок.Отбор;
  • ДинамическийСписок — предоставляет данные для списков и таблиц непосредственно из таблицы базы данных. Используется, например, в свойствах ПроизвольныйСписок.Источник, Таблица.Источник;
  • ИсточникДанныхМассив — предоставляет данные для списков и таблиц на основании массива;
  • КолонкаМатричнойГруппы — одна колонка матричной группы. Используется, например, в свойствах МатричнаяГруппа.Колонки, МатричнаяГруппа.ОписаниеАвтоматическихКолонок;
  • ПараметрВыбора — структура, описывающая фильтрацию сущностей при поиске;
  • ПрисоединеннаяТаблица — присоединенная таблица в динамическом списке. Используется, например, в свойстве ДинамическийСписок.ПрисоединенныеТаблицы;
  • СтрокаМатричнойГруппы — одна строка матричной группы. Используется, например, в свойствах МатричнаяГруппа.Строки, МатричнаяГруппа.ОписаниеАвтоматическихСтрок;
  • Сущность — объект данных, например, элемент справочника. Используется, например, в свойстве ФормаЭлемента.Сущность;
  • ЭлементМеню — один пункт меню;
  • ЭлементОтбора — одно условие отбора в динамическом списке. Используется, например, в свойствах ДинамическийСписок.Отбор, ПрисоединеннаяТаблица.Отбор;
  • ЭлементПорядка — одно условие сортировки в динамическом списке. Используется, например, в свойстве ДинамическийСписок.Порядок;
  • ЭлементСпискаЗначений — один элемент списка значений. Используется, например, в свойстве Переключатель.Элементы;
