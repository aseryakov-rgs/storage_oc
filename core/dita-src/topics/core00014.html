Свойства компонента интерфейса, унаследованного от компонента «ВыборДатыВремени»

Показывает календарь и элемент выбора времени, с помощью которых пользователь может ввести дату, время и интервал.

Иерархия наследования

  • Компонент (абстрактный)
    • ВыборДатыВремени

Свойства

Значение
Отображаемое и редактируемое значение. Может принимать значение одного из следующих типов: Неопределено, Момент, Дата, ДатаВремя, Время, ЗакрытыйДиапазон<Дата>, ЗакрытыйДиапазон<Время>, ЗакрытыйДиапазон<ДатаВремя>, ЗакрытыйДиапазон<Момент>
ССекундами
Признак того, что можно редактировать секунды. В этом режиме компонент показывает дополнительный элемент для выбора секунд.
ТипРедактирования
Тип редактируемого значения. Внешний вид компонента зависит от типа редактируемого значения.
Если тип редактируемого значения ДатаВремя, то в компоненте будут показаны элементы выбора и даты и времени.
Если тип редактируемого значения Дата, то в компоненте будут показан только элемент выбора даты.
Если тип редактируемого значения Время, то в компоненте будут показан только элемент выбора времени.
Если тип редактируемого значения ЗакрытыйДиапазон<Дата>, то в компоненте будет возможность выбора периода дат.
Если тип редактируемого значения ЗакрытыйДиапазон<Время>, то в компоненте будут показаны два элемента выбора времени — для начала и для конца интервала.

События

ПриИзменении
«1С:Кабинет сотрудника» вызывает это событие после установки нового значения в свойство Значение.
Пример YAML-файла:
ВидЭлемента: КомпонентИнтерфейса
ОбластьВидимости: Подсистема
Ид: a75d7a04-99ee-4432-ad3e-5bbdae5d3b51
Имя: МойВыборДатыВремени
Наследует:
    Тип: ВыборДатыВремени
    ПриИзменении: ОбработчикПриИзменении
Сигнатура обработчика события на встроенном языке:
метод ОбработчикПриИзменении(Источник: ВыборДатыВремени, 
                             Событие: СобытиеПриИзменении<Объект>)
;
