Свойства компонента интерфейса, унаследованного от компонента «СтандартнаяКолонкаТаблицы»

Одна колонка стандартного вида, см. Таблица.Колонки.

При описании вычисляемых свойств стандартной колонки таблицы можно использовать дополнительный параметр ДанныеЭлемента (подробнее).

Иерархия наследования

  • Компонент (абстрактный)
    • КолонкаТаблицы (абстрактный)
      • ПроизвольнаяКолонкаТаблицы
      • СтандартнаяКолонкаТаблицы

Свойства

Изображение
Задает картинку в ячейке. Если картинка не указана, а вид колонки = Картинка, будет отображаться картинка из данных, полученных через ПолеЗначения
Вид
Вид колонки таблицы:
  • Авто — Значение по умолчанию. Вид зависит от типа данных, отображаемых колонкой:
    • ДвоичныйОбъект.Ссылка — используется вид Картинка
    • Булево — используется вид Флажок
    • Остальное — используется вид Текст
  • Текст — колонка отображается в виде текста
  • Значок — колонка отображается в виде бейджа
  • ИконкаДействия — колонка отображается в виде иконки действия
  • Картинка — колонка отображается в виде картинки
Гиперссылка
Признак наличия гиперссылки в ячейке: Включено, Выключено, Авто. При значении Авто гиперссылка используется, если задан обработчик события ПриНажатии или в данных находится значение типа Сущность.Ссылка
МаксимальнаяВысотаВСтроках
Максимальная высота в строках текста таблицы. Применяется, когда Вид равен Текст. 0 — высота не ограничена
Представление
Представление значения, отображаемого в ячейке таблицы. Если представление не указано, а вид колонки равен Текст, то используется представление значения, полученное из свойства ПолеЗначения: 
ДанныеЭлемента[ПолеЗначения].Представление()
Ссылка
Задает ссылку, при этом текст и картинка в ячейке отображаются как гиперссылка, нажатие на которую вызывает событие ПриНажатии
СтилиОформления
Стили оформления ячейки
ЦветТекста
Цвет текста ячейки
ЦветФонаЗначка
Цвет фона значка. Применяется если Вид равно Значок

События

ПриНажатии
Метод, обрабатывающий событие нажатия на ссылку (текст или картинку) в строке таблицы. Метод должен находиться в модуле компонента.
Если этот метод возвращает Ложь, то происходит стандартная обработка нажатия на ссылку — ссылка открывается.
Если гиперссылка выключена (свойство Гиперссылка), то событие вызывается.
Пример YAML-файла:
ВидЭлемента: КомпонентИнтерфейса
ОбластьВидимости: Подсистема
Ид: c9d639e0-6865-47bc-bad7-6617ad2a8823
Имя: МояСтандартнаяКолонкаТаблицы
Наследует:
    Тип: СтандартнаяКолонкаТаблицы
    ПриНажатии: ОбработчикПриНажатии
Сигнатура обработчика события на встроенном языке:
метод ОбработчикПриНажатии(Источник: СтандартнаяКолонкаТаблицы, 
                           Событие: СобытиеПриНажатии, 
                           ДанныеЭлемента: Объект?)
;
