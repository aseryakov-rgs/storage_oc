Состав ресурсов и формат описания приложения для сборщика мобильных приложений

Ресурсы мобильного приложения представляют собой набор файлов в каталоге, либо в архиве.

Структура описания приложения

bundle.json
Описание приложения в формате JSON. Подробности здесь
icon-background.svg
Векторная картинка с фоном иконки приложения. Не должна быть прозрачной
icon.svg или icon-foreground.svg
Векторная картинка со значимой частью иконки приложения. Может быть прозрачной
google-services.json
Описание сопряжения с сервисами Google, которое выгружается из консоли сервисов Google
<ЛюбоеИмя>.mobileprovision
Профиль обеспечения. Название файла может быть любым, т. к. может быть только один профиль обеспечения

Векторные картинки со значимой и фоновой частью иконки используются для создания всех размеров иконок и заставок приложения. Фон и сама иконка указываются отдельно для того, чтобы создавать графику любого соотношения сторон. Если фон одноцветный, можно не указывать фоновую графику, а указать только саму иконку icon.svg. Цвет фона можно указать в описании. Если указана одна иконка и не указан цвет фона, то в качестве цвета фона будет использоваться цвет верхнего левого пикселя иконки.

Формат описания приложения

bundle.json представляет собой описание приложения в формате JSON. Он содержит объект с набором свойств идентифицирующим свойства приложения:

appId
Идентификатор приложения, например, com.e1c.mobile.ess
bundleName
Имя двоичного файла
version
Версия, например 1.0.20
build
Порядковый номер сборки, например 30
title
Заголовок, отображаемый, если язык устройства не совпадает ни с одним языком в списке localizedTitle
localizedTitle
Объект-карта с отображением языка в заголовок, например 
{ "en": "1C: Employee Office", "ru": "1С: Кабинет сотрудника" }
backgroundColor
Цвет фона иконок и заставок в формате #RRGGBB. Указывать только если фон однотонный и icon-background.svg не указана
serverURL
Адрес сервера для мобильного клиента
