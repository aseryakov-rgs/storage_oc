Где находится командный интерфейс

В этом примере вы найдете элемент проекта, который описывает командный интерфейс. Зная его вы сможете менять состав существующих команд и добавлять собственные команды.

При запуске веб-клиент ищет в проекте один из компонентов, унаследованных от СтандартноеКлиентскоеПриложениеСРазделами или ПроизвольноеКлиентскоеПриложение и запускает его экземпляр (подробнее).

Чтобы найти этот компонент откройте демонстрационное приложение DEMO CRM в среде разработки и выполните следующие действия:

  • Откройте панель SEARCH;

  • В строку поиска введите "КлиентскоеПриложение". Это позволит вам найти оба компонента, если они есть в проекте;

  • Будет найден один компонент — ДемонстрационноеПриложение (имя YAML-файла совпадает с именем компонента в проекте). Также из результатов поиска видно, что этот компонент находится в подсистеме Основное (подсистемы создают структуру каталогов, внутри которых находятся файлы проекта). Нажмите на строку «Тип: СтандартноеКлиентскоеПриложениеСРазделами», чтобы открыть YAML-файл;

  • Этот компонент интерфейса унаследован он компонента СтандартноеКлиентскоеПриложениеСРазделами. В свойстве КомандныйИнтерфейсПанелиНавигации у него находится элемент проекта, который как раз и описывает нужные вам команды. Имя этого элемента — ПанельНавигации. Введите это имя в строку поиска;

  • Будет найдено несколько файлов, в которых упоминается эта строка, но вам нужен последний, в котором описывается элемент проекта с таким именем. Нажмите на строку «Имя: ПанельНавигации», чтобы открыть YAML-файл;

  • Это элемент проекта вида ФрагментКомандногоИнтерфейса. В его свойстве Элементы перечисляются команды, которые вы видите на экране;

  • Теперь перейдите в панель 1C:PROJECT EXPLORER чтобы посмотреть, где находятся найденные элементы проекта;

  • Вкладки YAML-редактора синхронизированы с панелью 1C:PROJECT EXPLORER. Переключаясь с одной вкладки на другую вы видите редактируемый элемент в структуре проекта.
