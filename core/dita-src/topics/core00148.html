Как восстановить приложение из выгрузки, используя панель управления сервера

Чтобы восстановить приложение из выгрузки, выполните следующие действия:

  • Откройте ;
  • Нажмите Приложения и затем нажмите на интересующее вас приложение;
  • Нажмите Выгрузки приложения;
  • Выберите выгрузку, из которой вы хотите восстановить приложение, и нажмите Вернуть приложение к состоянию из выгрузки в меню выгрузки;
