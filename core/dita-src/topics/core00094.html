Как запустить сервер

Чтобы запустить сервер выполните следующие действия.

ОС Windows

Примечание:
  • В строку поиска введите "службы" ("services");
  • Запустите приложение Службы (Services);
  • Найдите в списке службу 1c-enterprise-element-server-with-ide;

  • Нажмите Запустить в контекстном меню;
  • В случае успешного запуска состояние службы изменится:

ОС Linux

Примечание:

Запустите терминал и выполните следующую команду:

systemctl start 1c-enterprise-element-server-with-ide
