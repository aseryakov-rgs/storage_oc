Пересчет дескрипторов и ключей

При самостоятельном формировании дескрипторов и ключей необходимо поддерживать их актуальность. Существует перечень ситуаций, в которых необходимо обеспечить их обновление.

Пересчет дескрипторов доступа

Пересчет дескрипторов доступа требуется в следующих случаях:

  • Если вы изменили алгоритм вычисления дескрипторов в обработчиках следующих событий:
    • ВычислитьДескрипторыДоступа
    • ВычислитьДескрипторыДоступаДляОбъектов
    • ВычислитьКлючиДоступаДляЧтения
    • ВычислитьКлючиДоступаДляИзменения
  • Если вы добавили в проект новый элемент, для которого поддерживается управление доступом (справочник, HTTP-сервис и т.д.). Вычисление дескрипторов доступа для всего элемента проекта не выполняется автоматически;
Пересчет дескрипторов можно вызвать:
  • Для одного элемента проекта, например, справочника Сотрудники:
    Сотрудники.ПересчитатьДескрипторыДоступа()
  • Для некоторых элементов данных или для всех элементов данных одного элемента проекта, например, для всех элементов справочника Сотрудники:
    Сотрудники.ПересчитатьДескрипторыДоступаДляОбъектов()
    Предупреждение: Эта операция может занять длительное время если, например, справочник содержит большое количество элементов.
    Важно: У периодического регистра сведений вызов этого метода приведет к вызову двух событий: ВычислитьКлючиДоступаДляЧтения и ВычислитьКлючиДоступаДляИзменения.
  • Для всех элементов проекта или для всех их объектов данных. Например, для всех справочников:
    для Справочник из Справочники
    Справочник.ПересчитатьДескрипторыДоступа()
;

Пересчет ключей доступа

Пересчет ключей доступа требуется в следующих случаях:
  • Если вы изменили алгоритм выдачи ключей в обработчиках событий <ИмяКлассаКлючейДоступа>.ПроверитьНаличиеКлючейДоступа;
  • Если изменились данные, на которых основывается выдача ключей тем или иным пользователям: принадлежность к той или иной роли, к тому или иному подразделению и т.д. Эти данные могут храниться в структурах, создаваемых другими элементами проекта или во внешней системе;
  • Если изменился набор параметров у какого-нибудь класса ключей доступа в проекте. В этом случае при обновлении приложения таблица ключей пользователя будет очищена. Соответственно нужно пересчитать ключи этого класса и дескрипторы, которые могли содержать ключи этого класса;
Пересчет ключей можно вызвать:
  • Для некоторых или для всех пользователей:
    Пользователи.ПересчитатьКлючиДоступа()
  • Для ключей определенного класса, например, для всех ключей класса КлючиГруппСотрудников:
    КлючиГруппСотрудников.ПересчитатьКлючи()
  • Для конкретного ключа (пересчитать ключ для некоторых или для всех пользователей):
    пер КлючМенеджеров = новый КлючиГруппСотрудников.Объект(ГруппыСотрудников.Менеджеры)
КлючМенеджеров.Пересчитать()
  • Для всех классов ключей доступа:
    для КлассКлючей из КлассыКлючейДоступа
    КлассКлючей.ПересчитатьКлючи()            
;
