Регистрация приложения «1С:Кабинет сотрудника»

Чтобы зарегистрировать приложение «1С:Кабинет сотрудника» выполните следующие действия:

  • Войдите в приложение на сервере;

  • Нажмите Перетащите файлы в окно или добавьте вручную и выберите файл settings.json из комплекта поставки. Параметры подключения будут заполнены:

    Совет: Для регистрации копий приложения вы можете использовать этот же файл settings.json.
  • Нажмите Сохранить;
  • Нажмите Зарегистрировать. Идентификатор приложения будет заполнен:

  • Создайте файл с настройками подключения для 1С:ЗУП, он понадобится вам при подключении 1С:ЗУП. Для этого введите внешний адрес приложения. Чтобы получить внешний адрес приложения возьмите адрес из адресной строки браузера (http://127.0.0.1:9090/applications/1SKabinet-sotrudnika) и замените в нем 127.0.0.1:9090 на имя вашего сервера, которое вы задали при настройке обратного прокси-сервера;

  • Нажмите Выгрузить файл настроек;
  • Нажмите Завершить регистрацию.
В процессе создания файла настроек приложение «1С:Кабинет сотрудника» создаст на сервере пользователя InfoSystem. Это тот пользователь, от имени которого 1С:ЗУП будет взаимодействовать с приложением. Чтобы увидеть этого пользователя, выполните следующие действия:
  • Откройте ;
  • Нажмите Приложения и нажмите на нужное приложение;
  • Нажмите Пользователи;
