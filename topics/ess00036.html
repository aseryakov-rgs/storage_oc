Системные требования

Приложение 1С:Предприятия 8

  • «1С:Зарплата и управление персоналом 8» (ПРОФ, КОРП) 3.1.14.166 и выше, базовая 3.1.14.305 и выше;
  • «1С:Зарплата и кадры государственного учреждения 8» (ПРОФ, КОРП) 3.1.14.166 и выше, базовая 3.1.14.305 и выше;
  • «1С:ERP Управление предприятием» 2.4.13.46 и выше;
  • «1С:Комплексная автоматизация» 2.4.13.46 и выше.
Примечание: В документации для примера используется приложение «1С:Зарплата и управление персоналом 8». В остальных прикладных решениях все действия выполняются аналогичным образом.

Сервер

Операционная система
  • Microsoft Windows 7 x64,
  • Microsoft Windows 10 x64,
  • Microsoft Windows Server 2012 x64 и выше,
  • Linux Ubuntu 20.04 x64,
  • Linux Alpine 3.11 x64,
  • Linux Astra Special Edition 1.7,
  • Linux РЕД ОС 7.3,
  • Linux РЕД ОС 8.
Важно: Если вы используете операционную систему Linux, убедитесь, что у вас установлена кодировка файлов UTF-8.
Java Platform
64-разрядная Java Runtime Environment (JRE) версии 17.
Предупреждение: При использовании Java других версий (например, Java 8, 11, 21, 22 и т. д.) работоспособность «1С:Предприятие.Элемента» не гарантируется.
Жесткий диск
Диск, на котором вы размещаете сервер, должен иметь не менее 1 Гб свободного места.
Оперативная память
Рекомендуется 8 Гб, но реальная потребность определяется используемым приложением и количеством пользователей.

Системы управления базами данных

  • PostgreSQL 10 и выше (подробнее);
  • Microsoft SQL Server 2008 R2 и выше (подробнее);
  • Файловая СУБД.

Браузеры для работы клиентского приложения

  • Google Chrome, последняя версия;
  • Mozilla Firefox, последняя версия;
  • Microsoft Edge, последняя версия;
  • Safari 14 и выше.

Операционные системы для работы мобильного клиентского приложения

  • Android 5.0 и выше;
    Предупреждение: При использовании Android 5.0 в мобильном приложении будет доступен вход только по логину и паролю. Вход по пин-коду будет недоступен.
  • iOS 14 и выше.
